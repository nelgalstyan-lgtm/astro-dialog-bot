# Astro Dialog Bot

Telegram-бот «Astro Dialog» — психологический профиль по знаку зодиака и психотипу,
с проверкой подписки на канал, финальными карточками-иллюстрациями и реферальной программой.

## Статус по знакам

Полный набор из 12 архетипов (готовые карточки на женский и мужской персонаж
+ деканы для детерминированного выбора) сейчас есть у **Овна**, **Тельца**,
**Близнецов**, **Льва**, **Весов**, **Скорпиона**, **Стрельца** и **Водолея**.
Остальные 4 знака (Рак, Дева, Козерог, Рыбы) пока работают по старой схеме —
один архетип на знак, карточка собирается автоматически из общего референса
(см. раздел «Как добавить архетипы другому знаку»).

> **На заметку по мере добавления остальных знаков:** карточки для восьми
> знаков уже весят около 400 МБ. Если оставшиеся 4 знака получат такой же
> полный набор — репозиторий вырастет примерно до 600 МБ. GitHub и Render
> это спокойно выдерживают, просто клонирование/деплой станет чуть дольше.
> Если объем станет неудобным — есть несложное решение (например, Git LFS
> или отдача картинок из внешнего облачного хранилища вместо репозитория),
> но пока в этом нет необходимости.

## Что нового в этой версии

1. **Добавлены полные наборы архетипов сразу для трёх знаков** — Овна
   (Первопроходец, Лидер, Борец, Зачинатель, Независимый, Импульсивный,
   Победитель, Защитник, Бунтарь, Охотник, Неудержимый, Завоеватель),
   Близнецов (Собеседник, Перевоплощение, Генератор идей, Исследователь,
   Рассказчик, Импровизатор, Посредник, Экспериментатор, Вечный ученик,
   Вестник, Авантюрист, Вольный дух) и Водолея (Новатор, Свободный,
   Визионер, Гуманист, Исследователь, Непохожий, Изобретатель, Мечтатель,
   Бунтарь, Объединитель, Независимый мыслитель, Проводник перемен).
   У каждого архетипа — готовая карточка на оба пола (24 файла на знак),
   архетип выбирается детерминированно по декану + времени рождения.
   Границы периодов и распределение архетипов по ним в описаниях не были
   заданы — распределили сами по смыслу (см. комментарии у
   `ARIES_DECANS` / `GEMINI_DECANS` / `AQUARIUS_DECANS` в `content.py`).

2. Ранее уже был добавлен полный набор для Тельца, Льва, Весов, Скорпиона
   и Стрельца — по той же схеме.

3. **Архетип вычисляется по дате и времени рождения, а не случайно.** Знак
   делится на 3 периода ("декана") по ~8-12 дней, в каждом — свои 4 архетипа.
   Внутри периода конкретный архетип выбирается по формуле
   `(день + час + минута) % 4` (если время рождения неизвестно — просто
   `день % 4`). Один и тот же человек всегда получает один и тот же архетип.

4. **Упрощенный финал сценария.** После ввода данных бот сразу присылает
   готовую карточку архетипа. Под карточкой — «📤 Поделиться ботом» и
   «🔄 Новый профиль».

5. **Готовые финальные карточки вместо генерации "на лету".** У бота два
   источника картинки: готовая иллюстрация архетипа из `assets/cards/`, а
   если для знака/архетипа готовой карточки еще нет — автоматическая
   заглушка, собранная из общего референса знака.

6. **Ничего не хранится на диске сервера.** Профиль пользователя и счетчик
   рефералов живут в оперативной памяти процесса.

7. **Бот готов к деплою на бесплатный хостинг** — режим webhook на своем
   `aiohttp`-сервере, с отдельным маршрутом `/` для health-check.

## Структура проекта

```
astro_bot/
├── bot.py                 # точка входа, все хендлеры и сценарий диалога
├── config.py               # конфигурация из .env / переменных окружения хостинга
├── content.py               # тексты + архетипы (8 знаков по 12 + деканы) + совместимость по стихиям
├── database.py             # хранилище пользователей в памяти процесса (без диска)
├── image_generator.py      # выбор готовой карточки архетипа либо генерация запасной
├── keyboards.py            # инлайн-клавиатуры
├── assets/
│   ├── references/         # общие референсы персонажей по знакам (для запасной карточки)
│   ├── cards/                # готовые финальные карточки архетипов (192 файла на сейчас)
│   ├── misc/                # логотип, обложка
│   └── fonts/                # DejaVu Sans (поддержка кириллицы, для запасной карточки)
├── requirements.txt
├── render.yaml              # Render Blueprint — деплой в пару кликов
├── .env.example
├── .gitignore
└── README.md
```

## Как добавить готовую карточку архетипа

Файл кладется в `assets/cards/` с именем `<id архетипа>_<пол>.png`, например:

```
assets/cards/cancer_02_female.png
assets/cards/cancer_02_male.png
```

Если карточка общая для обоих полов — можно назвать без суффикса пола:
`assets/cards/cancer_02.png`.

Бот сначала ищет файл `<id>_<пол>.png`, затем `<id>.png`, и только если ничего
не нашлось — собирает карточку сам. id архетипов по знакам (порядок — как в
`content.py`, `<ЗНАК>_TYPES`):

| Знак | Префикс id | Архетип 01 |
|---|---|---|
| Овен | `aries_01`…`aries_12` | Первопроходец |
| Телец | `taurus_01`…`taurus_12` | Хранитель |
| Близнецы | `gemini_01`…`gemini_12` | Собеседник |
| Лев | `leo_01`…`leo_12` | Король |
| Весы | `libra_01`…`libra_12` | Дипломат |
| Скорпион | `scorpio_01`…`scorpio_12` | Тень |
| Стрелец | `sagittarius_01`…`sagittarius_12` | Путешественник |
| Водолей | `aquarius_01`…`aquarius_12` | Новатор |

## Установка и локальный запуск (polling)

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Получите токен бота у [@BotFather](https://t.me/BotFather).

3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `CHANNEL_USERNAME`,
   `CHANNEL_URL`, `BOT_USERNAME`. `RUN_MODE` оставьте `polling`.

4. Добавьте бота **администратором** в канал (иначе бот не сможет проверять
   подписку через `getChatMember`).

5. Запустите:

   ```bash
   python bot.py
   ```

## Как добавить проект в GitHub

Если репозитория еще нет:

1. **Установите Git**, если его нет: [git-scm.com/downloads](https://git-scm.com/downloads).

2. **Создайте пустой репозиторий на GitHub:**
   - Зайдите на [github.com/new](https://github.com/new).
   - Укажите имя, например `astro-dialog-bot`.
   - **Не** ставьте галочки "Add README" / "Add .gitignore" — они уже есть
     в проекте, при их добавлении на GitHub возникнет конфликт при первой
     заливке.
   - Приватный или публичный — на ваш выбор (Render одинаково работает с обоими).
   - Нажмите **Create repository**.

3. **В терминале перейдите в папку `astro_bot`** (из распакованного архива)
   и выполните по порядку:

   ```bash
   cd astro_bot
   git init
   git add .
   git commit -m "Astro Dialog Bot"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/astro-dialog-bot.git
   git push -u origin main
   ```

   На `git push` GitHub спросит логин/пароль — вместо пароля нужен **Personal
   Access Token** (обычный пароль аккаунта GitHub больше не принимает с 2021
   года). Создать токен: **Settings → Developer settings → Personal access
   tokens → Tokens (classic) → Generate new token**, права достаточно
   отметить `repo`. Скопированный токен вставляется вместо пароля при push
   (логин — как обычно, ваш GitHub-username).

   Альтернатива без токенов каждый раз — [GitHub Desktop](https://desktop.github.com/):
   скачиваете, входите через браузер, "Add local repository" → указываете
   папку `astro_bot` → "Publish repository". Проще для тех, кто не хочет
   разбираться с токенами в терминале.

4. **Проверьте .gitignore.** Файл `.env` с вашим реальным токеном бота не
   должен попасть в репозиторий — он уже добавлен в `.gitignore`, но если вы
   создавали `.env` до `git init`, на всякий случай проверьте командой
   `git status`, что `.env` не появляется в списке файлов на коммит.

Если репозиторий уже есть и нужно просто обновить код (например, после
добавления новых знаков):

```bash
cd astro_bot
git add .
git commit -m "Добавлены архетипы для нового знака"
git push
```

Render (если уже подключен к этому репозиторию) подхватит изменения
автоматически при пуше в `main` и передеплоит сервис сам — заходить в
панель Render не нужно.

## Деплой на бесплатный сервер (Render.com)

Выбран **Render** — там реально бесплатный веб-сервис без карты и без
ограничения по времени. Ограничение одно: бесплатный веб-сервис "засыпает"
после ~15 минут без HTTP-запросов — но для бота это чинится штатной
бесплатной "будилкой" (шаг 5 ниже), после чего бот работает фактически
непрерывно.

### Шаг 1. Выложить код на GitHub

См. раздел выше.

### Шаг 2. Создать Web Service на Render

1. Зарегистрируйтесь на [render.com](https://render.com) и подключите GitHub.
2. **New +** → **Blueprint** → укажите репозиторий — Render подхватит
   `render.yaml` и попросит заполнить только секреты (`BOT_TOKEN`,
   `CHANNEL_USERNAME`, `CHANNEL_URL`, `BOT_USERNAME`).

   Или вручную: **New +** → **Web Service**, Build Command
   `pip install -r requirements.txt`, Start Command `python bot.py`, Plan
   Free, и те же переменные + `RUN_MODE=webhook`. Переменные `PORT` и
   `RENDER_EXTERNAL_URL` Render задает сам.
3. Через пару минут в логах увидите `Webhook зарегистрирован в Telegram` —
   бот уже отвечает.

### Шаг 3. Добавить бота администратором в канал

Иначе проверка подписки не сработает.

### Шаг 4. Проверить бота

Напишите боту `/start` в Telegram.

### Шаг 5. Не дать бесплатному сервису "засыпать"

1. Зарегистрируйтесь на [uptimerobot.com](https://uptimerobot.com) (бесплатно).
2. **Add New Monitor** → HTTP(s) → URL адреса вашего сервиса на Render.
3. Интервал проверки — 5 минут.

## Контент архетипов

Тексты архетипов лежат в `content.py`: `ARIES_TYPES`, `TAURUS_TYPES`,
`GEMINI_TYPES`, `LEO_TYPES`, `LIBRA_TYPES`, `SCORPIO_TYPES`,
`SAGITTARIUS_TYPES`, `AQUARIUS_TYPES` (по 12 каждый). Для остальных 4 знаков
(Рак, Дева, Козерог, Рыбы) — top-level поля знака в `ZODIAC` (`who_i_am`,
`love`, `work`, `strengths`, `archetype`, `main_force`, `main_weakness`,
`life_rule`) — там пока старый, единственный архетип на знак.

## Как добавить архетипы другому знаку

По уже отработанному образцу:

1. В `content.py` создайте `<ЗНАК>_TYPES` — список из 12 словарей с полями
   как у существующих (`id`, `title`, `main_force`, `main_weakness`,
   `life_rule`, при желании `subtitle`/`seen_as`/`hidden`/`hidden_pain`/
   `if_patience_ends`/`quote`).
2. Создайте `<ЗНАК>_DECANS` по образцу (3 периода дат, в каждом список из
   4 id архетипов) и добавьте в словарь знака `"decans": <ЗНАК>_DECANS`.
3. Добавьте в словарь знака `"types": <ЗНАК>_TYPES`.
4. Готово — бот сам подхватит новый набор.
5. Финальные иллюстрации кладите в `assets/cards/<id>_female.png` /
   `assets/cards/<id>_male.png`.

## Совместимость

Раздел «Совместимость» пока не подключен к сценарию бота, но алгоритм на
основе 4 стихий (Огонь / Земля / Воздух / Вода) остался в `content.py`
(`ELEMENT_COMPATIBILITY`, `get_element_compatibility`) — если раздел
понадобится вернуть, логика уже готова.
